# Simple Car Mod (Minecraft 1.21.1 Fabric)

Мод добавляет в Minecraft **1.21.1 (Fabric)** управляемый спорткар с 3D-моделью, вращающимися и поворачивающимися колёсами, выхлопным дымом и рецептом крафта.

## Как собрать готовый `.jar` файл

### Способ 1: Локально (если установлены JDK 21 и Gradle)
1. Откройте папку проекта в терминале (или откройте `build.gradle` в IntelliJ IDEA).
2. Выполните команду:
   ```bash
   gradle build
   ```
3. Готовый файл `simplecar-1.0.0.jar` появится в папке `build/libs/`.
4. Скопируйте его в папку `.minecraft/mods/` вместе с **Fabric API** для 1.21.1.

### Способ 2: Через GitHub Actions (без установки Java и Gradle на ПК)
1. Создайте новый репозиторий на GitHub и загрузите в него все файлы из этого архива.
2. Перейдите во вкладку **Actions** -> **Build Mod JAR** (сборка запустится автоматически).
3. Через 1–2 минуты скачайте готовый `.jar` из раздела **Artifacts** внизу страницы сборки.

## Управление в игре
- **ПКМ предметом «Спорткар» по земле** — поставить машину.
- **ПКМ по машине** — сесть за руль.
- **W / S** — газ / тормоз и задний ход.
- **A / D** — поворот руля.
- **Left Shift** — выйти из машины.
- **ЛКМ по машине (3 удара)** — подобрать машину обратно в предмет.
